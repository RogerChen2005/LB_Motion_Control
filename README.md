# LB：STM32F103ZET6 滑台控制器

HAL + 正点原子精英板 + ATK-MD0280 官方 BSP + 5 行 4 列矩阵键盘 + DM542。

## 操作

- 每次上电按官方提示用触摸笔点击五个校准点。校准期间电机不输出脉冲；校准参数暂不写入 Flash。
- 上键：按住正向点动；下键：按住反向点动；松开减速停止。运动中按反向点动会先减速到零，切换方向后再加速；速度输入时不接受点动。
- 数字键：在停止时输入整数速度，单位 mm/min。Enter 保存，F1 启动/停止。
- 左/右键：选择反向/正向；运行中选择另一方向会先减速到零，切换方向后再加速。Esc/F2：停止并退出输入。
- `*` 删除一位，`#` 清空并进入速度输入。
- 屏幕主界面点击速度区打开数字键盘；SAVE 保存，CANCEL 取消；START/PAUSE、STOP、REVERSE/FORWARD 与实体键一致；±JOG 按住运行，滑出按钮或松手停止。
- 上电必须先松开全部键；多键同时按下或键盘和触摸同时操作时停止请求，需要完全松开后再次操作。
- CMD 显示脉冲对应的指令速度及实际输出的 DIR 状态，没有编码器，不能视为实测速度或驱动器已识别的方向。

## 机械参数：先核对再通电运行

参数集中在 `App/Inc/machine_config.h`：

| 参数 | 当前值 |
|---|---|
| 丝杠导程（按电机直连丝杠） | 4 mm/rev |
| 每电机圈脉冲数 | **25600，按用户照片中的 SW5～SW8 拨码** |
| 默认速度 | 60 mm/min |
| 点动速度 | 1200 mm/min |
| 允许输入 | 0～1200 mm/min；0 不启动 |
| 加减速度 | 480 (mm/min)/s |

用户照片中 SW5～SW8 均拨向远离 ON 的一侧，即 **OFF/OFF/OFF/OFF**；驱动器外壳表格对应 **25600 pulse/rev**。如果之后调整拨码，应同步修改 `PULSES_PER_REV`。SW1～3 用于电流设置，程序不改变它。

`f(Hz) = v(mm/min) × PPR / (60 × 4)`。
当前为 25600 ÷ 4 = 6400 pulse/mm。例如 240 mm/min 对应 25600 Hz；点动 1200 mm/min 对应 128000 Hz。
点动松手采用减速停车：当前默认参数从最高速度1200降至0约2.5秒，理想制动距离约25mm。实际还取决于机械负载、失步和扫描延迟。

## 接线

| 功能 | STM32 引脚 |
|---|---|
| 键盘第1～5行 | PA15、PA13、PA11、PC9、PC7 |
| 键盘第1～4列 | PG2、PG4、PG6、PG8（用户实测列序） |
| STEP/PUL 输出 | PA7 / TIM3_CH2 |
| DIR 输出 | PE6 |
| ENA+ 输出 | PE1，低电平使能；ENA− 接控制地 |
| USB串口诊断 | PA9 TX、PA10 RX；115200、8N1，按开发板跳帽接 USART1 |
| 调试接口 | JTAG/SWD 在固件启动时关闭；PA13 用作键盘输入 |

键盘直插照片中 P1 右列从 PA15 到 PG2 的连续 9 针；行线依次为 PA15 至 PC7，用户修正后的逻辑列序为 PG2 至 PG8。键盘是无源触点，不给排线加5V。行开漏扫描，列3.3V上拉，非选中行释放。此排针的 PG6/PG8、PC9、PA11、PA15 与板载无线模块、TF卡、USB/CAN、ATK模块接口复用；不要连接或启用这些外设，核对相关跳帽后再直插。

PA13 原是 SWDIO；固件启动时关闭整个 JTAG/SWD 并把它用作键盘列线。此后无法在运行中的固件上连接 SWD 调试器。保留 BOOT0/USART1 的恢复烧录途径；如需 SWD 调试，先断开键盘，并使用复原 SWD 配置的固件。

LCD 插在原有接口，官方 BSP 使用 FSMC Bank4/PG12片选、PG0命令数据选择、PB0背光；触摸使用 PB1时钟、PB2输入、PF9输出、PF10 PEN、PF11片选，不需要占用键盘引脚。

用户可改的 GPIO 统一写在 `App/Inc/board_pins.h`：DIR、ENA、矩阵键盘行列、背光和触摸笔的软件 SPI。每次改线同时修改对应的 `PORT` 与 `PIN`，并检查是否和板载设备冲突。TIM3_CH2、USART1 和 LCD FSMC 的 AFIO 引脚在同一文件中列出，但保持当前硬件映射。官方 BSP 仍位于 `Drivers/BSP`；其引脚宏引用此配置文件。

STM32输出为3.3V，而照片中DM542控制输入标为5～24V。当前程序按 PA7 脉冲、PE6 方向、PE1 低电平使能编写；用户实测断开 ENA 后正反转均正常，说明原来的 PE1 高电平接入 ENA 会阻止运动。普通停止后 PE1 保持低电平以维持电机保持力；故障关断时 PE1 拉高。接回 ENA 前应断电，重新上电后先低速验证；若接回后仍不能运动，可继续让 ENA+/ENA− 悬空并核对驱动器完整型号。PE1 的 3.3V 高电平不一定满足驱动器可靠关断规格，软件故障关断不能替代硬件急停。不得将5V/24V接入GPIO。

方向逻辑：PE6 低为正向，PE6 高为反向。切换方向时软件先把 STEP 降到零，再改变 PE6，等待约20ms后重新发脉冲。主界面 CMD 后的 DIR:FWD/REV 显示的是软件输出状态，不代表驱动器光耦已识别。若屏幕显示 DIR:REV 且 CMD 升速、机械却仍向前，分别测量板端 PE6、驱动器 DIR+ 对 DIR− 在正反向时的电压；若高电平仅约3.3V，应采用适合驱动器输入规格的5V接口电路，不能把5V直接送入STM32引脚。

驱动器动力电源按铭牌20～50V，线圈仍接A±/B±。先断开机械负载或确认可用行程，再低速核对方向和实际位移。当前工程未接限位开关、编码器和硬件急停；Esc与屏幕STOP是软件减速命令，停车后仍保持使能。需要硬件急停和行程限位时应接独立电路后联调。

## 工程与构建

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

输出：`build/Debug/LB.elf`、`LB.hex`、`LB.bin`，BIN烧录起始地址0x08000000。采用现有CMake/Ninja/arm-none-eabi-gcc。

- `Core`：CubeMX 生成的启动、主循环、中断和 HAL 配置。
- `App/Inc` 与 `App/Src`：自己编写的状态机、调度、键盘、脉冲、串口、屏幕和触摸模块。`board_clock.c` 使用板载8MHz HSE配置72MHz。
- `App/Port/SYSTEM`：官方示例所需的 GCC/HAL 兼容层，微秒延时使用DWT，不改写SysTick。
- `App/Src/ui.c`：320×240 横屏主界面和数字键盘；主界面按钮下方显示 `Ver2.0 by ZJU Atomic Lab`。
- `Drivers/BSP/ATK_MD0280`：从指定的《精英STM32F103开发板.zip》引入官方驱动。
- `cmake/lb_app.cmake`：应用及驱动构建清单、HAL模块开关和HEX/BIN输出。

CubeMX基础工程保持标准结构。新增代码在独立文件中，main/中断调用位于USER CODE区；外设初始化由应用及官方BSP负责，因此`.ioc`不是完整的外设配置视图，不要在CubeMX重复配置这些引脚/定时器。`.ioc`不分配 PA13/PA14 调试口。CubeMX再次生成后检查 `stm32f1xx_hal_msp.c` 仍关闭 JTAG/SWD、`cmake/lb_app.cmake` 仍被包含，新增HAL源文件仍在Drivers中，并重新编译。

主循环刷新屏幕，SysTick扫描键盘并每10ms调整速度，脉冲由TIM3硬件输出。触摸采样超过80ms未更新会释放触摸按键；主循环超过250ms无响应会锁定运动并减速，需复位恢复。

## 官方驱动改动记录

原始来源：用户提供的《精英STM32F103开发板.zip》中的 `Drivers/BSP/ATK_MD0280`，文件版权头保留。
LCD初始化、FSMC时序、字库和触摸SPI保留官方实现。`atk_md0280_touch.c`仅调整：

1. 不稳定ADC采样最多重试8次，失败返回错误；松手后的数据不作为触摸点。
2. 校准验证失败直接重新校准，修复原流程可能写到`point[5]`越界的问题。
3. 旋转坐标的边界减1，避免生成等于屏宽/屏高的越界坐标。

`atk_md0280.c` 的清屏、字符及字符串边界改用当前显示宽高，使开机竖屏触摸校准后可切换为 320×240 横屏；`display_panel.c` 在校准完成后设置 90° 显示方向。

BSP 的四个引脚头文件另外引用 `App/Inc/board_pins.h`，默认接线和官方板卡一致。修改用户可配 GPIO 时只需改应用配置头文件；升级官方 BSP 时应重新检查这些引脚宏。

官方校准流程保留，每次开机重新校准。若LCD初始化失败，运动保持禁用，串口报告读到的ID。
